SERVIDOR DNS - UBUNTU SERVER (BIND9)
Zona: aulalinux.local | Rede: Classe C - 192.168.0.0/24
=========================================================

------------------------------------------------------------
1. ATUALIZAÇÃO E INSTALAÇÃO DOS PACOTES
------------------------------------------------------------

sudo apt update
sudo apt upgrade -y
sudo apt install bind9 bind9utils bind9-doc dnsutils -y

------------------------------------------------------------
2. CONFIGURAR AS DUAS PLACAS DE REDE (netplan)
------------------------------------------------------------

Edite o arquivo de configuração de rede em /etc/netplan/ (o nome do
arquivo pode variar, ex: 00-installer-config.yaml). Exemplo com duas
interfaces: uma na rede interna (onde o DNS vai atuar) e outra para
acesso externo/gerência.

sudo nano /etc/netplan/00-installer-config.yaml

network:
  version: 2
  ethernets:
    enp0s3:              # Placa 1 - rede interna (DNS)
      addresses:
        - 192.168.0.1/24
      nameservers:
        addresses: [127.0.0.1]
    enp0s8:               # Placa 2 - rede externa/gerência
      dhcp4: true

Aplique a configuração:

sudo netplan apply
ip a          # confirme se as duas interfaces subiram corretamente

------------------------------------------------------------
3. CONFIGURAR /etc/bind/named.conf.options
------------------------------------------------------------

sudo nano /etc/bind/named.conf.options

acl internal-network {
    192.168.0.0/24;
};

options {
        directory "/var/cache/bind";
        allow-query { localhost; internal-network; };
        allow-transfer { localhost; };
        forwarders {
           8.8.8.8;
           8.8.4.4;
        };
        recursion yes;
        dnssec-validation no;
        listen-on { any; };
#       listen-on-v6 { any; };
};

Obs.: ajuste o(s) IP(s) de "forwarders" para o DNS público ou
corporativo real disponível na sua rede.

------------------------------------------------------------
4. CONFIGURAR /etc/bind/named.conf.local
------------------------------------------------------------

sudo nano /etc/bind/named.conf.local

zone "aulalinux.local" IN {
        type master;
        file "/etc/bind/forward.aulalinux.local";
        allow-update { none; };
};

zone "0.168.192.in-addr.arpa" IN {
        type master;
        file "/etc/bind/reverse.aulalinux.local";
        allow-update { none; };
};

------------------------------------------------------------
5. CRIAR A ZONA DE BUSCA DIRETA (forward)
------------------------------------------------------------

Os arquivos de zona de amostra (db.local) já estão em /etc/bind,
podemos copiá-los como base:

cd /etc/bind
sudo cp db.local forward.aulalinux.local
sudo nano forward.aulalinux.local

$TTL 604800
@ IN SOA primary.aulalinux.local. root.aulalinux.local. (
                                   2026090301 ; Serial (AAAAMMDDnn)
                                   3600       ; Refresh
                                   1800       ; Retry
                                   604800     ; Expire
                                   604600 )   ; Negative Cache TTL

; Name Server
@       IN  NS    primary.aulalinux.local.

; IP do próprio servidor DNS
primary IN  A     192.168.0.1

; Mail Server (MX)
aulalinux.local. IN MX 10   mail.aulalinux.local.

; Registros A exigidos pela tarefa
teste   IN  A    192.168.0.1
www     IN  A    192.168.0.1
mail    IN  A    192.168.0.1

; CNAME (opcional)
ftp     IN  CNAME www.aulalinux.local.

------------------------------------------------------------
6. CRIAR A ZONA DE BUSCA REVERSA (reverse)
------------------------------------------------------------

sudo cp db.127 reverse.aulalinux.local
sudo nano /etc/bind/reverse.aulalinux.local

$TTL 86400
@ IN SOA primary.aulalinux.local. root.aulalinux.local. (
                           2026090301 ; Serial
                           3600       ; Refresh
                           1800       ; Retry
                           604800     ; Expire
                           86400 )    ; Minimum TTL

; Name Server
@ IN NS primary.aulalinux.local.

; PTR canônico do único IP em uso (boa prática: 1 PTR por IP)
1  IN PTR  primary.aulalinux.local.

Obs.: como teste, www e mail apontam para o mesmo IP (192.168.0.1),
mantenha apenas UM registro PTR (o nome canônico do host). Ter
múltiplos PTR para o mesmo IP não é recomendado.

------------------------------------------------------------
7. AJUSTAR O SERVIÇO PARA ESCUTAR EM IPv4
------------------------------------------------------------

sudo nano /etc/default/named

OPTIONS="-u bind -4"

------------------------------------------------------------
8. VALIDAR SINTAXE DAS ZONAS
------------------------------------------------------------

named-checkconf
named-checkzone aulalinux.local /etc/bind/forward.aulalinux.local
named-checkzone 0.168.192.in-addr.arpa /etc/bind/reverse.aulalinux.local

------------------------------------------------------------
9. REINICIAR E HABILITAR O SERVIÇO
------------------------------------------------------------

sudo systemctl stop bind9
sudo systemctl start bind9
sudo systemctl enable bind9
sudo systemctl status bind9

(No Ubuntu, "bind9" e "named" apontam para o mesmo serviço via
symlink; use "systemctl status bind9" para confirmar o estado.)

------------------------------------------------------------
10. CONFIGURAR O CLIENTE PARA USAR O DNS
------------------------------------------------------------

No cliente (ou no próprio servidor), aponte o DNS para 192.168.0.1
(via /etc/resolv.conf, netplan ou configuração de rede da máquina
cliente).

------------------------------------------------------------
11. TESTES FINAIS (ping e nslookup)
------------------------------------------------------------

nslookup teste.aulalinux.local
nslookup www.aulalinux.local
nslookup mail.aulalinux.local
nslookup 192.168.0.1        ; teste de resolução reversa

ping -c 4 teste.aulalinux.local
ping -c 4 www.aulalinux.local
ping -c 4 mail.aulalinux.local

Todos os comandos devem retornar o IP 192.168.0.1 e responder ao
ping normalmente, confirmando que o servidor DNS está resolvendo
corretamente a zona aulalinux.local.
