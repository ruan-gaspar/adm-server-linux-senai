Reiniciar o servidor
sudo systemctl restart slapd

Instalar os pacotes referentes ao serviço
sudo apt install slapd ldap-utils -y

após instalação execuar o comando

sudo dpkg-reconfigure slapd
selecione a opção "Não"
selecione a opção "sim" para remover a base de dados
selecione a opção "não" para não mover a base de dados antiga
